# 📒 Trader Journal — Дневник трейдера

**Trader Journal** — это оффлайн-дневник трейдера в виде Progressive Web App (PWA).
Он помогает вести учёт сделок, считать **R:R**, отслеживать **Win Rate**, **просадку** и планировать нужный депозит для цели.

> ⚠️ **Не является финансовым советом.** Это инструмент для самоанализа и дисциплины.

---

## 🚀 Возможности

### 📊 Учёт сделок
- Добавление, редактирование и удаление сделок.
- Поддержка Long и Short.
- Учёт комиссий и абонентской платы за тариф.
- Автоматический расчёт прибыли, риска и R:R.

### 🧮 Калькулятор R:R
- Считает **тейк-профит** для заданного R:R.
- Показывает варианты TP для 1:2, 1:3, 1:4.
- Оценивает сделку: «плохая», «средняя», «хорошая», «отличная».
- Кнопка «Применить в форму» — переносит значения в сделку.

### 💰 Пополнение депозита
- Отдельный блок для пополнений (не портит Win Rate и R:R).
- Учитывается в депозите и на графике.
- Список пополнений с датой и комментарием.

### 📈 Статистика
- Win Rate (% прибыльных сделок).
- Средний R:R по всем сделкам.
- Прибыль от сделок.
- Сумма пополнений.
- Итоговый депозит.
- Максимальная просадка.

### 📊 График доходности
- Зелёная линия — рост депозита.
- Красная линия — просадка.
- Учитывает и сделки, и пополнения.

### 🎯 Планировщик депозита
- Вводишь цель (в ₽) и период.
- Получаешь необходимый риск на сделку и нужный депозит.
- Расчёт основан на Win Rate 60% и R:R 1:2.

### 🧠 Советы
- Автоматические подсказки на основе твоей статистики.
- Например: «Win Rate ниже 50% — проверь входы».

### 💾 Резервная копия
- Экспорт всех данных в JSON.
- Импорт из JSON для восстановления.
- Экспорт в CSV (Excel) для анализа.

### 📱 PWA
- Работает **оффлайн**.
- Можно **установить** на телефон или компьютер.
- Тёмная и светлая темы.

## 🛠️ Установка

### Локально
1. Скачай все файлы:
   - `index.html`
   - `manifest.json`
   - `service-worker.js`
   - `icon.png` (иконка 512×512)
2. Открой `index.html` в браузере.

### GitHub Pages
1. Залей файлы в репозиторий.
2. Включи **Settings → Pages → Deploy from branch**.
3. Открой ссылку — приложение готово.

### Установка как PWA
- **Chrome/Edge:** нажми на иконку «Установить» в адресной строке.
- **iOS Safari:** «Поделиться» → «На экран “Домой”».

## 📝 Как пользоваться

### 1. Пополни депозит
- Введи сумму в блоке **«💰 Пополнение депозита»**.
- Укажи дату и комментарий.
- Нажми **«Добавить пополнение»**.

### 2. Найди сигнал
- Дождись касания уровня поддержки/сопротивления.
- Проверь MACD (пересечение) и RSI (зона 30/70).
- Открой калькулятор R:R, введи цену входа и стоп.
- Получи цену TP и проверь, есть ли там уровень.

### 3. Добавь сделку
- Заполни поля: инструмент, направление, вход, выход, стоп, количество.
- Укажи комиссии (вход и выход).
- Нажми **«Сохранить»**.

### 4. Анализируй
- Смотри **Win Rate**, **средний R:R**, **просадку**.
- Раз в неделю открывай **«🧠 Советы»** и **«📊 По инструментам»**.
- Экспортируй данные в JSON для резервной копии.

## 🧠 Формулы

### R:R
```
R:R = |Цена выхода − Цена входа| / |Цена входа − Стоп-лосс|
```

### Прибыль
```
Long:  (Выход − Вход) × Кол-во − Комиссии
Short: (Вход − Выход) × Кол-во − Комиссии
```

### Win Rate
```
Win Rate = Прибыльные сделки / Всего сделок × 100%
```

### Просадка
```
Просадка = Максимум(Пик − Текущий депозит)
```

## 🎯 Целевые показатели

| Метрика | Цель |
| :--- | :--- |
| **Win Rate** | ≥ 50% |
| **Средний R:R** | ≥ 1.5 |
| **Просадка** | ≤ 30% от прибыли |
| **Риск на сделку** | ≤ 1% от депозита |

## 🧰 Технологии

- **HTML + CSS + JavaScript** — без фреймворков.
- **Dexie.js** — локальная база данных (IndexedDB).
- **Chart.js** — графики.
- **Service Worker** — оффлайн-режим.
- **Web App Manifest** — установка как PWA.
